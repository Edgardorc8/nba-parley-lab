# NBA Parley Lab

Aplicación web local para análisis cuantitativo NBA (Motor 65/35 + Z-Score + Devigging + Steam Moves + Player Props + Historial SQLite + Excel).

## Cómo ejecutar en otra PC (Windows)
1. Clona el repositorio:
   ```bash
   git clone https://github.com/Edgardorc8/nba-parley-lab.git
   cd nba-parley-lab
   ```
2. Haz doble clic en **`iniciar.bat`** (instala automáticamente `openpyxl`, `fastapi` y `uvicorn`, y abre `http://localhost:8000`).
